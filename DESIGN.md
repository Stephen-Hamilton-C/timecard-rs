# Time Periods

Time periods will be a new system that help the user determine how much time
they need to work each day to reach a total number of hours worked in a time period.

## Requirements

* The user must be able to configure...
    * how many hours they must work each day
    * which days of the week are considered business days
    * which days will be considered PTO
    * when time periods start and end
    * whether hours are to be rounded by the tenth, quarter, half, or whole, or if individual minutes are used
* The user must be able to view the current time period and expected hours for each day
* If no time period is configured, the feature is simply unused
